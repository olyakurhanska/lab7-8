# Лабораторні роботи №7–8

**Тема:** Розробка та тестування моделей даних з Django/Flask: від визначення до PyTest валідації.

## Мета роботи

Набути практичних навичок створення моделей даних у Django та Flask, налаштування зв'язків між ними, виконання міграцій, роботи з ORM-запитами та автоматизованого тестування програм за допомогою PyTest.

## Опис проєкту

У лабораторних роботах №7–8 було продовжено розробку вебдодатків «Каталог книг», створених у попередніх лабораторних роботах.

Проєкт складається з двох частин:
- `django_project` — вебдодаток на Django.
- `flask_project` — вебдодаток на Flask.

В обох додатках реалізовано моделі для зберігання інформації про книги, авторів, категорії та додаткові характеристики книг. Для роботи з базами даних використано SQLite.

## Виконані завдання

### Завдання 1. Створення моделей Django

Створено чотири моделі: `Author`, `Category`, `Book` та `BookDetail`.

Реалізовано зв'язки один-до-багатьох, багато-до-багатьох та один-до-одного. Для кожної моделі визначено поля, обмеження, налаштування `Meta` та метод `__str__`.

### Завдання 2. Міграції Django

Створено дві міграції:
- `0001_initial` — створення початкової структури таблиць.
- `0002_book_rating` — додавання поля рейтингу книги.

Міграції застосовано та перевірено за допомогою команд `migrate`, `showmigrations` і `sqlmigrate`.

### Завдання 3. Моделі та міграції Flask

Створено аналогічні моделі за допомогою Flask-SQLAlchemy.

Для керування міграціями використано Flask-Migrate. Реалізовано початкову ревізію бази даних і другу ревізію для додавання поля `rating`.

Перевірено історію міграцій та структуру таблиць SQLite.

### Завдання 4. ORM-запити та CRUD

Для обох фреймворків реалізовано операції створення, читання, оновлення та видалення записів.

У Django виконано фільтрацію `filter()`, виключення `exclude()`, складні запити з Q-об'єктами, агрегацію `aggregate()`, анотацію `annotate()` та оптимізацію запитів за допомогою `select_related()` і `prefetch_related()`.

У Flask реалізовано аналогічні CRUD-операції та продемонстровано роботу транзакцій через `db.session.commit()` і `db.session.rollback()`.

### Завдання 5. Автоматизоване тестування моделей

За допомогою PyTest створено тести для перевірки моделей обох додатків.

Перевірено створення об'єктів, значення за замовчуванням, обмеження полів, зв'язки між таблицями та каскадне видалення.

Для підготовки тестових даних використано фікстури `conftest.py`, а для перевірки різних значень — параметризацію.

### Завдання 6. Інтеграційне HTTP-тестування

Реалізовано тести маршрутів та вебсторінок Django і Flask.

Перевірено HTTP-статуси `200`, `302`, `404`, правильність відображення сторінок, роботу форм, серверну валідацію та реакцію на некоректні дані.

У Flask також перевірено надсилання форми без CSRF-токена.

### Завдання 7. Мок-тестування та покриття коду

Створено мок-тести за допомогою `unittest.mock.patch`.

Перевірено роботу функції надсилання електронного повідомлення без реального підключення до поштового сервера, а також отримання поточного року з підміною системного часу.

За допомогою `pytest-cov` отримано звіти про покриття коду.

## Запуск проєктів

Для запуску потрібні Python та бібліотеки, зазначені у відповідних файлах `requirements.txt`.

### Django

Перейдіть у папку `django_project` та виконайте:

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Після запуску сайт доступний за локальною адресою `http://127.0.0.1:8000/`.

### Flask

Перейдіть у папку `flask_project` та виконайте:

```powershell
python -m pip install -r requirements.txt
python -m flask --app app db upgrade
python app.py
```

Після запуску сайт доступний за локальною адресою `http://127.0.0.1:5000/`.

Обидві адреси працюють локально на комп'ютері із запущеним сервером.

## Запуск тестів

**Django:**

```powershell
cd django_project
python -m pytest -v
python -m pytest --cov=books --cov-report=term-missing
```

**Flask:**

```powershell
cd flask_project
python -m pytest -v
python -m pytest --cov=app --cov=models --cov=forms --cov=services --cov-report=term-missing
```
